ShowKey by Kaprrrr Studios

Play a recording in the key you use onstage while the song keeps its original tempo.
ShowKey runs in Google Chrome on a Windows PC or Mac (Chrome 116 or newer). If you
need Chrome, download Google Chrome for your computer
(https://www.google.com/chrome/).

Download ShowKey-Chrome.zip
https://github.com/Kaprrrr/ShowKey/releases/latest/download/ShowKey-Chrome.zip

Find the heading INSTALL ON WINDOWS or INSTALL ON MAC below. If someone sent you the ZIP, you can
start at step 2 for your computer. If you’ve already extracted it and see
START-HERE.txt beside manifest.json, start at step 4. If ShowKey is already
installed, use Update a copy you already installed.

The ZIP contains a folder’s worth of files. You’ll unpack them, put them somewhere
permanent, then tell Chrome where to find them. For a keyboard shortcut such as
Ctrl+C, hold the first key, tap the second key, then release both. Inside the
download, START-HERE.txt contains these same directions and opens in Notepad on
Windows or TextEdit on Mac.

INSTALL ON WINDOWS

1. Download the ZIP. Copy the download address at the top of this guide into Chrome
   and press Enter. If you’re on the GitHub release page instead, scroll to Assets
   and click ShowKey-Chrome.zip. If Chrome asks where to save it, choose Downloads
   and click Save.

2. Find it on your PC. Hold the Windows logo key and press E to open File Explorer.
   Click Downloads on the left, or open the location where you saved the file. Look
   for ShowKey-Chrome.zip. Windows may display it as ShowKey-Chrome with a zipper on
   the folder icon.

3. Unzip it. Right-click that zipped folder and choose Extract All…. Leave the
   suggested destination in place and click Extract. You should now have a regular
   folder called ShowKey-Chrome as well as the original ZIP. If the regular folder
   is already open and you can see START-HERE.txt inside, you’ve completed this
   step.

4. Keep the regular folder in Documents. In File Explorer, go back to Downloads (or
   your chosen download location). Click the regular ShowKey-Chrome folder once and
   press Ctrl+C to copy it. Click Documents on the left and press Ctrl+V to paste it
   there. Open the new ShowKey-Chrome folder in Documents. You should see
   START-HERE.txt and a file called manifest.json (sometimes shown as manifest).
   Chrome will use this folder every time you practice, so leave it in Documents.

5. Open Chrome’s extensions page. Open Google Chrome from the Start menu or your
   taskbar. Click the address bar at the very top, type chrome://extensions, and
   press Enter. You should see a page titled Extensions.

6. Show the installation button. Find Developer mode near the upper-right corner of
   that page. Click its switch to turn it on. A button called Load unpacked appears
   near the upper left. This setting lets Chrome open the folder you just copied.

7. Choose the ShowKey folder. Click Load unpacked. In the window that opens, click
   Documents on the left. Click ShowKey-Chrome once, then click Select Folder. If
   you already opened the folder in this window, click Select Folder while you are
   inside it. Chrome’s folder picker may hide the individual files; that’s normal.

8. Find ShowKey in Chrome. Look for a ShowKey card on the Extensions page. That
   means it’s installed. Click the puzzle-piece icon near the top-right corner of
   Chrome, beside the address bar. Find ShowKey in that menu and click the pin
   beside it. Its green icon will now stay beside the address bar. Continue to Play
   your first song below.

INSTALL ON MAC

1. Download the ZIP. Copy the download address at the top of this guide into Chrome
   and press Enter. On the GitHub release page, you can also scroll to Assets and
   click ShowKey-Chrome.zip. If your browser asks where to save it, choose
   Downloads.

2. Find it in Finder. Click the Finder icon (the blue smiling face) in the Dock.
   Click Downloads in the left sidebar. If you don’t see Downloads, choose Go from
   the menu bar at the very top of the screen, then Downloads. If you saved the ZIP
   somewhere else, open that location.

3. Unzip it. Double-click ShowKey-Chrome.zip. A regular folder called ShowKey-Chrome
   should appear beside it. Some browsers unzip files automatically. If you already
   see a regular folder with START-HERE.txt inside, use that folder.

4. Keep the regular folder in Documents. Click the ShowKey-Chrome folder once and
   press Command (⌘) + C. Click Documents in the Finder sidebar, or choose Go and
   then Documents from the menu bar. Press Command (⌘) + V to paste the folder
   there. Double-click the new folder and look for START-HERE.txt and manifest.json
   (Finder may hide the filename endings). Leave this folder in Documents so Chrome
   can find it the next time you practice.

5. Open Google Chrome. Press Command (⌘) + Space, type Google Chrome, and press
   Return. In Chrome, click the address bar at the very top, type
   chrome://extensions, and press Return. You should see Chrome’s Extensions page.
   This ZIP is for desktop Chrome; Safari, iPhone, and iPad use different
   extensions.

6. Show the installation button. Find the Developer mode switch near the upper right
   of the Extensions page and turn it on. Click Load unpacked near the upper left. A
   window opens so you can choose a folder.

7. Choose the ShowKey folder. Click Documents on the left side of the window. Click
   the ShowKey-Chrome folder once, then click Select or Open at the bottom right. If
   you already opened the folder, click Select or Open while you’re inside it.
   Chrome will read the files inside it.

8. Find ShowKey in Chrome. A ShowKey card should now appear on the Extensions page.
   Click the puzzle-piece icon beside Chrome’s address bar, find ShowKey, and click
   its pin. Look for the green ShowKey icon beside the address bar. You’re ready to
   try a song.

PLAY YOUR FIRST SONG

1. Open a new Chrome tab, go to YouTube, open a song’s video, and press Play. Keep
   that tab selected so ShowKey knows which sound to change.

2. Click the green ShowKey icon beside the address bar. You should see ShowKey with
   by Kaprrrr Studios underneath and the title of your video.

3. Under Recording key, choose the key you hear on the record. Under Show key,
   choose the key you play in. For example, if the recording is in A and your band
   plays it in G, choose A and G. The display should read −2 half steps.

4. Click Start live audio and play along. Listen for the lower key at the same
   tempo. If you don’t know the recording’s key, leave Recording key on By ear,
   click Start live audio, and tap − or + until the recording matches your guitar.
   Each tap changes the sound by one fret’s worth of pitch.

5. Click + Save song to remember this recording and key. You can close the popup and
   keep playing. Next rehearsal, open the song from Your setlist, play it, then open
   ShowKey in that tab and click Start live audio.

6. To hear the original recording again, click Stop live audio. To end playback,
   pause the song on its own page.

IF SOMETHING LOOKS DIFFERENT

- I see “Source code (zip)” on GitHub. Choose the asset named ShowKey-Chrome.zip for
  the packaged extension and the plain-text guide.

- Chrome says it can’t find the manifest. Open the folder in File Explorer or
  Finder. Look for manifest.json beside START-HERE.txt. If you see another
  ShowKey-Chrome folder inside, open that inner folder. Go back to Load unpacked and
  choose the folder that directly contains those files.

- I can’t see “Load unpacked.” Check that you typed chrome://extensions in Google
  Chrome’s address bar and turned on Developer mode. On a work or school computer,
  the administrator may control this setting.

- I installed it, but the green icon is missing. Click Chrome’s puzzle-piece icon to
  find ShowKey and pin it. If the puzzle piece is hidden, widen the Chrome window.
  You can also check the ShowKey card at chrome://extensions to see whether it’s
  enabled.

- I want to use Apple Music. Open Apple Music in Chrome (https://music.apple.com),
  sign in if needed, and play the track in that tab. ShowKey processes sound from
  the selected browser tab. A song playing in the separate Music app or on another
  device plays outside that tab. Our Windows tests confirmed YouTube playback and
  Apple Music web previews. Full Apple Music subscription tracks and Mac playback
  remain unverified. The signed-out Spotify web player produced no audible output in
  testing. If a track goes silent after you start ShowKey, click Stop live audio to
  restore ordinary playback.

- “Save song” is grey. Open the individual song or video page. ShowKey uses that
  page’s link to find your recording next time.

UPDATE A COPY YOU ALREADY INSTALLED

1. Download the latest ShowKey-Chrome.zip and unzip it in Downloads.

2. Open the new regular folder. Select the files inside, including the vendor
   folder, and copy them.

3. Open the folder you originally selected with Load unpacked. Paste the copied
   files there. If your computer asks about files with the same names, choose
   Replace. Keeping the same folder lets Chrome recognize your existing
   installation.

4. Open chrome://extensions. On the ShowKey card, click the circular arrow labeled
   Reload. Open ShowKey again on a playing music tab.

ABOUT SHOWKEY

The − and + buttons cover one octave in either direction. The key menus use the
shortest shift between two notes. A major to G major and A minor to G minor both use
−2. When a live YouTube tab moves to another video, ShowKey recalls its saved shift
or starts at zero. Pitch processing adds a short delay to the sound.

ShowKey processes the tab’s audio on your computer. It saves song links, titles, and
tuning settings in your Chrome profile. It uses Signalsmith Stretch 1.3.2
(https://github.com/Signalsmith-Audio/signalsmith-stretch) for pitch shifting. The
vendor folder contains the audio engine and its license notices.
